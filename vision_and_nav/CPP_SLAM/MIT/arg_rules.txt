This is mainly implemented in a way to make the parser very simple

- Comments, start with #, any line starting with # is ignored when parsing, so comments can be placed anywhere
 but for simplicity not at the end of lines, all lines end with ;, except comments
- options, there are many parameters to tweak, all of them can be changed here.
    i) parameters are grouped, so things retaining to RANSAC look like this:
RANSAC_(model) #Note there are settings for PnP and essential matrix, separate
#Each line after here, first what part is being set, followed by a :, example:
    GROUP
    RANSAC_E
    PARAM
    METHOD:USAC_DEFAULT;
    PARAM
    THRESHOLD:1e-3;
    ENDG;
so there are some reserved keyphrases, GROUP, PARAM, GROUP-specifies what group the following PARAM belong to,
at the end of the document there is a list of all keyphrases, and their usage, all groups / other phrases must end with 
END;

KEYPHRASES:
GROUP-specifies what group (algorithm) the following parameters refer to, note the table, GROUP_PARAMS, defines what 
PARAMs a GROUP has, and all valid groups are defined there
PARAM-specifies the value of a PARAM
DATASET-specifies what dataset to use, see below for details
VALID GROUPS:

RANSAC_PNP
